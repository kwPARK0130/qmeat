# Qmeat · 육류 유통 시장 워크스페이스

실데이터를 가져와 조회하고 견적의 원가·판매가격을 계산하는 한국어 웹앱입니다. API 인증이 없어도 공식 CSV/XLSX와 수동 확인 환율로 사용할 수 있습니다. 임의 시세나 회사자료를 넣지 않습니다.

## 실행

Python 3.12 기준으로 검증했습니다.

```bash
cd /workspace/qmeat
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 3000
```

브라우저에서 실행한 서버의 3000번 포트를 여세요. 백엔드가 웹 화면과 API를 함께 제공합니다. 로컬 기본 설정은 인증 없는 단일 조직 워크스페이스입니다. 공용 서버 배포는 포함하지 않습니다. 네트워크에 공개하기 전 `.env.example`의 `QMEAT_USERS`를 **환경변수로** 설정하고 HTTPS를 적용하세요. 사용자 인증 후 조직은 서버 설정에서 결정하며 계산·검색·가져오기 기록은 조직별로 제한됩니다. 공개 통계·고시환율·갱신 작업은 공용입니다. `.env`는 자동으로 읽지 않습니다.

## 사용 순서

1. **파일 가져오기**에서 공식 통계 파일(CSV, XLSX)을 선택합니다. 공식 내려받기 링크가 화면에 있습니다.
2. 시트명·헤더 행·제공처·분류 버전·중량·금액 단위·국가 역할을 선택하고 열 이름을 연결합니다. 첫 미리보기에서 실제 헤더·시트 목록을 확인할 수 있습니다.
3. 미리보기의 정상행과 행별 오류를 확인하고 확정합니다. 오류가 있으면 정상행만 저장할지 명시적으로 선택합니다. HS 코드는 Excel에서도 문자형으로 보존하세요. 기간은 `YYYY-MM`입니다.
4. 시장 통계에서 기간·품목코드·국가·축종·보관·출처를 조회합니다. 검색은 저장 자료만 읽으며 원자료 요청은 별도 비동기 작업입니다.
5. 관심 검색을 저장하거나 원가 계산기를 사용합니다. 가격·중량·환율은 실제 확인한 값으로 입력하세요. 빈 비용은 미확정이며 정산 완료로 저장할 수 없습니다.

## 구현 범위

- 공통 필터·URL 상태·월별 차트·서버 집계·표 페이지·국가 비교·전월/전년/누계 비교
- 중량 가중 평균, 상위/하위 코드 중복 방지, 제공처·국가 역할·분류 버전 구분, 빠진 월의 빈 값
- 관심 품목/저장 검색의 고정 기간·최근 N개월 정책
- CSV/XLSX 시트·헤더·열 연결, 단위 정규화, 오류행 확인, 논리키 중복 방지, 수정 이력
- 통계 CSV/XLSX와 원가 Excel 내보내기(조회조건·정책 포함, 수식 주입 방지)
- 환율 실제 고시일·원/100외화 정규화, 외화·중량·가격 단위 환산
- 십진수 원가·목표마진·가산율·부분판매·회수가능 세금·필요자금 계산
- 변경 불가능한 원가 스냅샷과 복사 후 새 버전 저장
- SQLite WAL 영속 저장, 수집 원본 참조·수정 이력·수집 범위
- 비동기 갱신·작업 중복 방지·DB 리스·하위 구간·취소·실패 구간 재시도
- 기본 매일 서울 12:00 예약, 백엔드 재시작 시 최근 누락 예약 보충

## 실제 데이터 연결 상태

| 출처 | 현재 사용 경로 | 자동 API |
|---|---|---|
| 관세청 국가·품목별 수입 | 공식 파일 가져오기 | 어댑터 구현, 공식 문서 및 실응답 검증 필요 |
| 식약처 일반통계 | 공식 파일 가져오기 | 제공 API 미확인, 자동 연결 미지원 |
| 한국수출입은행 고시환율 | 출처·실제 고시일을 포함한 사용자 입력 | 어댑터 구현, 키 및 공식 문서 검증 필요 |

구현 환경에서 `www.data.go.kr` 접근은 프록시 403으로 차단되었고 API 키도 제공되지 않았습니다. 자동 API는 기본 비활성입니다. 문서의 인증·현재 상세 경로·단위·페이지·한도를 확인하고 실제 응답을 검증한 뒤 `CUSTOMS_API_KEY`, `EXIM_API_KEY`, `QMEAT_ENABLE_UNVERIFIED_API=1`을 설정해야 합니다. 연결 성공을 주장하지 않습니다. 필요한 네트워크 도메인: `www.data.go.kr`, `apis.data.go.kr`, `www.koreaexim.go.kr`, `oapi.koreaexim.go.kr`, `impfood.mfds.go.kr`, `tradedata.go.kr`. 외부 API 키는 브라우저에 전송하지 않습니다.

관세청 어댑터의 경로 후보는 `/1220000/nitemtrade/getNitemtradeList`, 환율은 `/site/program/financial/exchangeJSON`입니다. 문서상의 계약을 구현했으나 현 환경에서 공식 확인하지 못했으므로 활성화 게이트를 두었습니다. 페이지가 잘렸다는 증거가 있으면 성공으로 저장하지 않습니다. 관세청 자동 조회에는 명시적인 품목코드와 국가가 필요합니다. 파일은 완전한 전체시장으로 간주하지 않으며 비중은 **조회 국가 중 비중**으로 표시합니다. 값이 없는 월을 0으로 만들지 않습니다. 관세청·식약처 통계를 합산하지 않습니다.

## 예약·장애 복구

예약 주체는 서버 백그라운드 실행기입니다. 화면을 닫아도 서버가 켜져 있으면 실행됩니다. PC/서버가 꺼져 있으면 실행되지 않으며 재시작 때 최근 누락 예약을 보충하고 실제 시각을 기록합니다. 여러 프로세스는 SQLite 쓰기 잠금과 120초 작업 리스로 중복을 막습니다. 외부 요청 제한시간은 30초입니다.

매일 저장 검색의 최근 3개월, 환율 최근 14일을 확인합니다. 매월 1일에는 최근 36개월을 확인합니다. 36개월보다 오래된 보유 자료의 전체 정정 재확인은 현재 수동 기간 조회가 필요합니다. 초기 36개월 적재는 기간을 지정한 원자료 조회로 실행합니다. 기간은 12개월씩 분할합니다. 일시 오류는 최초 시도 후 최대 3회 재시도(60/300/900초, 숫자 Retry-After 우선)합니다. 인증 오류는 자동 재시도하지 않습니다. 실패한 범위는 성공 범위로 표시하지 않으며 이전 정상 관측을 유지합니다.

## 계산 정책

Python Decimal 28자리, 중간 반올림 없음, 화면 표시 최대 소수 2자리입니다. 실제 청구 원단위 확정은 별도 정산 정책이 필요합니다. kg당 원가는 총 도입원가÷판매가능 중량, 판매분 원가는 kg당 원가×판매 중량입니다. 판매가능 중량에 포함된 감량을 또 차감하지 않습니다. 포함 비용은 추가하지 않고 회수가능 세금은 현금지출에만 포함합니다. 미입력 비용을 제외한 결과는 잠정치입니다. 목표마진과 원가가산율은 별도 결과입니다. 저장된 입력·환율·결과·수식 버전은 이후 환율 변경에 영향받지 않습니다.
